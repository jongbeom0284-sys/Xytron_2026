SSH 로 직접 띄우면 연결이 끊기는 순간 SIGHUP 으로 런치가 같이 죽는다.
실제로 0824 00:30 에 그렇게 죽었다. tmux 안이면 끊겨도 계속 달린다.

| 하고 싶은 것 | 키 / 명령 |
| --- | --- |
| 빠져나오기 (차는 계속 달림) | `Ctrl+B` 떼고 `D` |

## 3. 한 바퀴 동작

```
빨간불 정지 → 초록불 → 콘 → 정지차량 → 이동차량 → S자 → 신호등
                                                         ├ 직진 → 위와 동일
                                                         └ 좌회전 → 바로 S자
```

| 구간 | 무엇이 도나 |
| --- | --- |
| 신호 대기 | 신호등 인식만 |
| 직진 | 흰선 중앙 추종, 1.9 m/s |
| 콘 | 라이다 벽 추종. 앞차 인식·라이다 회피 모두 끔 |
| **콘 탈출** | 라이다 무장 (10초), 앞차 창 30초 시작 |
| 정지차량 | **라이다**. 확정하면 반대쪽 흰선으로, 그 즉시 라이다 끔 |
| 이동차량 | **욜로**. 라이다 유지 시간이 끝나면 켜진다 |
| S자 | 차선 주행 + 곡선 감속 |

좌회전 바퀴는 콘·차량이 없으므로 라이다도 욜로도 켜지지 않는다. 정상이다.

- 현재 미션에 `▶`

- 정지차·회피는 **확정 순간의 값을 붙잡고** 끝나면 사라진다. 괄호는 경과 초

## 7. 아직 없는 것 (알고 있어야 한다)

미션을 놓쳤을 때 **손으로 넘길 수단이 없다.** 아래는 만들지 않았다.

| 상황 | 지금 벌어지는 일 |
| --- | --- |
| 초록불을 못 봄 | 콘 트리거가 영영 무장 안 됨 → 콘 구간 통째로 놓침 |
| 직진을 좌회전으로 오판 | 위와 같음 |
| 좌회전을 직진으로 오판 | 없는 콘 구간을 찾아감 |
| 주황을 못 봄 | 콘 사이를 차선 주행으로 뚫으려 함 |
| 콘 모드가 안 끝남 | 이후 구간 전부 막힘 |
| 정지차량·이동차량을 못 봄 | 회피 없이 그대로 감 |

그리고 **차선을 놓쳐도(LOST) 속도가 안 줄어든다.** 실측에서 9초를 그대로
간 적이 있다. 곡선 감속이 들어가 덜 놓치겠지만 그물은 없다.

미션 실패는 재시도 기회가 주어지므로, 그때 `~/race_halt.sh` 로 세우고
다시 시작하는 것이 지금의 대응이다.
