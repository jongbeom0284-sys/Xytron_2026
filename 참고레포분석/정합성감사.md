# kmu_race 코드-문서 정합성 감사 (2026-08-16)

원칙: "params.yaml 문서 블록과 README 가 튜닝의 지도" — 문서 드리프트는 대회 당일 사고다.
대상: `xycar_ws/src/kmu_race/` 전체. 모든 라인 번호는 감사 시점 기준.

## 요약

- **값 불일치 1건**: `speed_to_mps` — yaml 0.08 vs `race_node.py:67` declare 기본값 **0.055**
- **의미가 낡은 docstring 2건 (심각)**: `types.py` gantry_span_px(옛 원-span 서술), `cone_detector.py` 모듈 docstring(옛 좌/우 분할 알고리즘 서술)
- **README 낡은 수치 1건**: 테스트 78개 → 실제 정의 88개(kobot 최근 실행 기록 85 통과)
- 문서 블록에 나열된 파라미터의 **값 자체는 speed_to_mps 를 제외하고 전수 일치**
- ★급인데 문서 블록에 누락된 튜닝값 다수 (아래 1-C)

**speed_to_mps 불일치의 의미**: `ros2 launch`(race/debug)로 실행하면 yaml 의 0.08 이 이기므로 본선 경로는 안전하다. 그러나 `ros2 run kmu_race race` 로 직접 실행하거나 params_file 로딩이 실패하면 **0.055 로 조용히 떨어진다**. 이 값은 `ego_speed_mps` 환산(race_node.py:203)을 거쳐 `FSMConfig.moving_ratio` 기반 고정장애물↔방해차량 판별에 직결된다. 0.055/0.08 = 31% 과소평가 → 정지 물체를 '주행 중'으로 오판하는 쪽으로 치우친다. declare 기본값을 0.08 로 맞출 것.

선언 목록 자체는 yaml 상단 9개와 1:1 로 정확히 일치 (문서에만 있거나 코드에만 있는 노드 파라미터 없음).
