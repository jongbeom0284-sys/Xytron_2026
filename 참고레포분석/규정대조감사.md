## 3. 규정 원문 자체의 특이사항 (주최측 확인 권장)

- **p.22 산술 불일치**: "15번(벌초 합산 60초)" — 15회×5초=75초≠60초. 12회=60초인지 15회가 기준인지 모호. 코드 주석은 원문을 그대로 옮겼으므로 코드 잘못은 아니나, 실격 기준선이 12회일 가능성 있음.
- **p.5 vs p.6 미션 순서 불일치**: p.5 텍스트는 "신호등→라바콘→차선인식→고정장애물→추월", p.6 도면은 "①신호등 ②차선 ③라바콘 ④고정장애물 ⑤방해차량". FSM 이 반응형(순서 하드코딩 없음)이라 어느 쪽이어도 동작 — 설계가 이 모호성을 정확히 흡수함.
- p.3 "대회 진행 방식과 미션은 대회 직전까지 변경될 수 있습니다" — README 가 이미 인용, 매핑표 유지보수 체계도 그에 맞게 설계됨.
